# shared/db/migrations — Alembic migration scripts

## Setup (Phase 1)

1. `alembic init src/shared/db/migrations`
2. Edit `env.py`:
   - Import async engine from `shared/config.py`
   - Use `run_async_migrations()` pattern (asyncpg requires asyncio run mode)
   - Set `target_metadata = Base.metadata` from `shared/db/models.py`
3. Edit `alembic.ini` — set `sqlalchemy.url` to blank (loaded dynamically in `env.py`)

## First migration

```bash
alembic revision --autogenerate -m "initial_schema"
alembic upgrade head
```

Creates: `tenants`, `tenant_keys`, `policies`, `ledger_entries`

## Convention

- One migration per logical change; always review autogenerated SQL before committing
- Always implement `downgrade()` — no one-way migrations
- Never use `--autogenerate` blindly in production
